## Premissas acadêmicas / dados simulados

Velocidades, custos, risco, disponibilidade de modal, infraestrutura aérea simulada e margens operacionais são parâmetros demonstrativos. O Índice LifeBox, quando apresentado com telemetria, é apenas índice acadêmico de condição logística e não probabilidade clínica.
